# 📌 Untitled

## 🧾 Descripción
Es un sistema de gestion que apunta al sector educativo.

## 🎯 Objetivo
Es un proyecto personal de practica y tambien para mi portafolio.

## 🧠 Tecnologías
- fast api(Backend)
- React(frontend)
## 🚀 Funcionalidades
- [x] Poder agregar, editar y desactivar estudiantes, con matrícula manual o automática configurable.
- [x] Poder agregar, editar y desactivar maestros.
- [x] Poder agregar, editar y eliminar secciones.
- [x] Asignar notas a estudiantes individualmente o por sección.
- [x] Poder ver el histórico de notas por estudiante.
- [x] Que el maestro pueda pasar lista por fecha en las secciones asignadas.
- [x] Seleccionar, agregar, editar y eliminar asignaturas.
- [x] Registrar cargos y pagos internos sin pasarela externa.
- [x] Asignar balance, día de corte y día límite al estudiante.
- [x] Ver horarios según las materias inscritas o asignadas.
- [x] Crear pensums y mostrar materias aprobadas, cursando y pendientes.
- [x] Inscribir estudiantes, validando duplicados, prerrequisitos y choques de horario.
- [x] Autenticación con access token y renovación segura.
- [x] Roles de administración, docente y estudiante con permisos diferenciados.

## ✅ Soluciones
